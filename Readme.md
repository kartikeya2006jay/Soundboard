# 🎧 SoundBoard — A Simple Web Audio Project

Welcome to **SoundBoard**, a fun beginner-friendly project built using **HTML, CSS, and JavaScript**.  
This mini-app helps you understand how the **Audio API** works with simple user interactions.

---

## 🚀 Features

- 🎵 Click any sound tile to **play / pause** the audio  
- 🖼️ Interactive images with optional animations  
- 🎚️ Color-changing heading effect  
- 🗂️ Clean folder structure  
- 🧠 Great for beginners learning DOM + Audio API  

---

## 🛠️ How It Works

Each sound box has a class like `a`, `b`, `c`, etc.  
These letters match the audio files inside the **sounds** folder.

When a box is clicked:

1. JavaScript detects the class  
2. Loads the matching `.mp3` file  
3. If the sound is playing → it stops  
4. If the sound is paused → it plays  

Simple and clean toggle behavior.
